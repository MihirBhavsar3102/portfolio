## Context

A personal project: a CI/CD pipeline with security gates built into its build and deploy stages. It ships a three-tier Java application to a self-managed Kubernetes cluster, and it runs on every push.

## Architecture

<Diagram />

A push to GitHub fires a webhook, and Jenkins runs the pipeline. Maven builds the application, SonarQube runs static analysis on the code, and OWASP Dependency-Check scans its dependencies. The pipeline then builds a Docker image, Trivy scans that image, and the application is deployed to the cluster. SonarQube, Dependency-Check and Trivy are the security gates.
