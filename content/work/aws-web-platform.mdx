## Context

At Parkar Global Technologies I designed and deployed a WordPress platform on AWS built to tolerate faults: it runs across availability zones behind a load balancer. Its infrastructure is defined in Terraform, so a new environment comes from code and can be replicated in one step.

## Architecture

<Diagram />

CloudFront, with S3, sits in front of an Application Load Balancer, which spreads traffic across EC2 instances in an Auto Scaling group that spans availability zones. WordPress runs on those instances, with its database in RDS.

A GitHub Actions pipeline ships changes end to end: Terraform provisions the infrastructure with plan and apply, and Ansible handles configuration. CloudWatch alarms and dashboards watch the platform, and I built Grafana dashboards and alert rules on a Prometheus stack that was already running.
